## 🌟 Overview

This portfolio is an interactive narrative experience divided into 7 cinematic chapters:

- **01 — Hero:** Interactive introduction, live status telemetry, and character-driven monologue.
- **02 — About:** Engineering philosophy, foundational pillars, and interactive tech focus nodes.
- **03 — Experience:** Practical engineering track record across MERN stack and scalable backend systems.
- **04 — Projects:** Production systems showcase with interactive architecture diagrams and key engineering outcomes:
  - *Geo-Attendance System* (GPS geofenced anti-proxy attendance)
  - *SafeDischarge AI* (Agentic clinical discharge summary pipeline)
  - *MyLoanCredit.com* (Live fintech loan processing engine)
  - *Hostel Roommate Sync* (Campus-scale mutual allocation platform)
  - *Dispatch Load Balancer* (Java 24 / Spring Boot 3.5 fleet routing)
- **05 — Skills / Tech Universe:** Interactive multi-category constellations across Languages, Backend, Databases, AI/GenAI, Core Engineering, and Cloud Tools.
- **06 — AI / Achievements:** GenAI architectures, Gemini API integrations, deterministic prompt pipelines, and competition achievements.
- **07 — Contact / Final Scene:** Welcoming character stage, one-click copy direct channels, client-side message composer, and minimal footer.

## 🛠️ Tech Stack

- **Framework:** React 18
- **Bundler & Dev Server:** Vite 5
- **3D & Canvas:** Three.js, React Three Fiber, GLSL Shaders
- **Icons:** Lucide React
- **Styling:** Custom Vanilla CSS Design System with dark cyberpunk / cinematic aesthetics
- **Character Animation:** High-performance MP4 video playback with IntersectionObserver viewport auto-pause

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher recommended)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/shubh100802/Portfolio.git

# Navigate to the project directory
cd Portfolio

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

The app will be available at `http://localhost:5173/` (or the next available port).

### Production Build

```bash
npm run build
```

The built production bundle will be generated in the `dist/` directory.
